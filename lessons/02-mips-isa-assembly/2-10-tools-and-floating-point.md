## ۱. شبیه‌سازهای QtSpim و MARS

اسلاید درس می‌گوید تنها راه یاد گرفتن اسمبلی، نوشتن مقدار زیادی کد و اجرای آن است. ما پردازنده‌ی MIPS واقعی نداریم، پس از **شبیه‌ساز (Simulator)** استفاده می‌کنیم. شبیه‌ساز برنامه‌ی اسمبلی را می‌خواند، به زبان ماشین تبدیل می‌کند، اجرا می‌کند و محتوای ثبات‌ها و حافظه را نشان می‌دهد.

دو شبیه‌ساز رایج داریم:

| ویژگی | شبیه‌ساز QtSpim | شبیه‌ساز MARS |
|---|---|---|
| سازنده | جیمز لاروس (James Larus) | دانشگاه ایالتی میزوری |
| پیش‌نیاز | ندارد | جاوا (Java Runtime) |
| ویرایشگر داخلی | ندارد، فایل را جدا می‌نویسی | دارد |
| ترتیب بایت | مثل ماشین میزبان (روی PC کوچک‌پایان) | همیشه کوچک‌پایان |
| شروع برنامه | برچسب `main` | اولین دستور بخش `.text` |
| کاربرد در درس | فایل‌های نمونه‌ی درس برای آن است | برای اشکال‌زدایی راحت‌تر است |

نام SPIM همان MIPS است که برعکس نوشته شده. پیوست A کتاب COD کامل درباره‌ی SPIM توضیح می‌دهد. فایل‌های نمونه‌ی درس (پوشه‌ی QuSpim) برای QtSpim نوشته شده‌اند، ولی روی MARS هم اجرا می‌شوند. پیشنهاد من: QtSpim را برای سازگاری با درس و MARS را برای اشکال‌زدایی نصب کن.

## ۲. نصب روی لینوکس مینت

### نصب QtSpim

فایل نصب را از صفحه‌ی رسمی پروژه بگیر: <https://sourceforge.net/projects/spimsimulator/files/>. آخرین نسخه‌ی فعلی 9.1.24 است. فایل لینوکس پسوند `.deb` دارد. بعد از دانلود در پوشه‌ی Downloads:

```bash
cd ~/Downloads
sudo apt install ./qtspim_9.1.24_linux64.deb
qtspim &
```

اگر نام فایل نسخه‌ی دیگری داشت، همان نام را بنویس. دستور `apt install` با مسیر فایل، وابستگی‌ها را هم خودش نصب می‌کند.

یک نسخه‌ی خط فرمان هم در مخزن‌های اوبونتو و مینت هست:

```bash
sudo apt install spim
spim -file example1.s
```

### نصب MARS

شبیه‌ساز MARS یک فایل `jar` است و فقط جاوا لازم دارد:

```bash
sudo apt install default-jre
java -version
```

فایل `Mars4_5.jar` را از صفحه‌ی رسمی MARS بگیر: <https://dpetersanderson.github.io/>. بعد اجرا کن:

```bash
cd ~/Downloads
java -jar Mars4_5.jar
```

برای اجرای یک برنامه از خط فرمان بدون محیط گرافیکی:

```bash
java -jar Mars4_5.jar nc example1.s
```

گزینه‌ی `nc` یعنی پیغام کپی‌رایت را چاپ نکن.

## ۳. نصب روی ویندوز

### نصب QtSpim

از همان صفحه‌ی SourceForge فایل `QtSpim_9.1.24_Windows.msi` را دانلود کن، روی آن دوبار کلیک کن و مراحل نصب را جلو برو. بعد از منوی Start برنامه‌ی QtSpim را باز کن.

### نصب MARS

ابتدا جاوا را نصب کن. یک نسخه‌ی رایگان و رسمی، Eclipse Temurin از سایت <https://adoptium.net/> است. بعد فایل `Mars4_5.jar` را دانلود کن و روی آن دوبار کلیک کن. اگر باز نشد، در PowerShell بنویس:

```powershell
cd $HOME\Downloads
java -jar Mars4_5.jar
```

## ۴. اولین برنامه و کار با شبیه‌ساز

فایل `example1.s` درس این است (کمی کوتاه‌شده):

```asm
        .text
        .globl main
main:   li   $v0, 4            # syscall 4: print_string
        la   $a0, msg          # address of the string
        syscall
        li   $v0, 10           # syscall 10: exit
        syscall

        .data
msg:    .asciiz "Hello World!\n"
```

### در QtSpim

1. از منوی File گزینه‌ی Reinitialize and Load File را بزن و فایل را انتخاب کن.
2. دکمه‌ی Run (مثلث سبز) یا کلید F5 را بزن. خروجی در پنجره‌ی Console دیده می‌شود.
3. برای اجرای قدم‌به‌قدم کلید F10 را بزن و تغییر ثبات‌ها را در پنجره‌ی سمت چپ ببین.

به چند نکته در QtSpim دقت کن:

- **کد شروع:** QtSpim قبل از برنامه‌ی تو یک کد کوچک شروع (Kernel startup) اجرا می‌کند که `main` را با `jal` صدا می‌زند. پس برنامه باید برچسب `main` داشته باشد.
- **تنظیمات:** از منوی Simulator و گزینه‌ی Settings، بخش MIPS، مطمئن شو گزینه‌ی Enable delayed branches خاموش و گزینه‌ی Accept pseudo instructions روشن است.
- **پنجره‌ی متن:** هر سطر نشان می‌دهد شبه‌دستورات به چه دستورات واقعی تبدیل شده‌اند. مثلاً `la` را به `lui` و `ori` تبدیل شده می‌بینی.

### در MARS

1. فایل را با File و Open باز کن یا در ویرایشگر داخلی بنویس.
2. کلید F3 را بزن تا اسمبل شود. صفحه‌ی Execute باز می‌شود.
3. کلید F5 برنامه را کامل اجرا می‌کند و کلید F7 یک دستور جلو می‌رود.
4. ثبات‌ها در سمت راست و حافظه در پایین دیده می‌شوند. ستون Basic در بخش Text Segment دستورات واقعی را نشان می‌دهد.

در منوی Settings گزینه‌ی Delayed branching به‌طور پیش‌فرض خاموش است. همین‌طور نگهش دار.

## ۵. فراخوانی‌های سیستمی

برنامه‌ی اسمبلی برای ورودی و خروجی از سیستم‌عامل کمک می‌گیرد. در شبیه‌سازها این کار با دستور `syscall` انجام می‌شود. قاعده:

1. شماره‌ی سرویس را در `$v0` بگذار.
2. آرگومان‌ها را در `$a0` تا `$a3` یا `$f12` بگذار.
3. دستور `syscall` را اجرا کن.
4. نتیجه (اگر باشد) در `$v0` یا `$f0` است.

| سرویس | شماره در `$v0` | ورودی | خروجی |
|---|---|---|---|
| چاپ عدد صحیح `print_int` | 1 | ثبات `$a0` | – |
| چاپ عدد اعشاری `print_float` | 2 | ثبات `$f12` | – |
| چاپ عدد دقت مضاعف `print_double` | 3 | ثبات `$f12` | – |
| چاپ رشته `print_string` | 4 | ثبات `$a0` = آدرس رشته | – |
| خواندن عدد صحیح `read_int` | 5 | – | ثبات `$v0` |
| خواندن عدد اعشاری `read_float` | 6 | – | ثبات `$f0` |
| خواندن عدد دقت مضاعف `read_double` | 7 | – | ثبات `$f0` |
| خواندن رشته `read_string` | 8 | ثبات `$a0` = بافر، `$a1` = طول | – |
| گرفتن حافظه‌ی پویا `sbrk` | 9 | ثبات `$a0` = تعداد بایت | ثبات `$v0` = آدرس |
| پایان برنامه `exit` | 10 | – | – |
| چاپ کاراکتر `print_char` | 11 | ثبات `$a0` | – |
| خواندن کاراکتر `read_char` | 12 | – | ثبات `$v0` |

سرویس ۹ مثل `malloc` ساده عمل می‌کند. MARS سرویس‌های بیشتری هم دارد، مثل عدد تصادفی (۴۲) و پنجره‌ی پیغام، ولی این‌ها در QtSpim نیستند.

### مثال: جمع دو عدد

فایل `example3_io.s` درس همین کار را می‌کند. خلاصه‌ی آن:

```asm
        .text
        .globl main
main:   li   $v0, 5            # read_int
        syscall
        move $t0, $v0          # A
        li   $v0, 5            # read_int
        syscall
        add  $a0, $t0, $v0     # A + B
        li   $v0, 1            # print_int
        syscall
        li   $v0, 10           # exit
        syscall
```

## ۶. دستورات ممیز شناور به‌طور خلاصه

دو سؤال امتحانی و تمرین درس با آرایه‌ی ممیز شناور کار می‌کنند. نمایش IEEE 754 و سخت‌افزار ممیز شناور را در بخش ۳ کامل می‌خوانیم. اینجا فقط حداقلی را می‌گوییم که برای نوشتن برنامه لازم است.

### کمک‌پردازنده‌ی ۱ و ثبات‌ها

در MIPS دستورات ممیز شناور در واحدی به نام **کمک‌پردازنده‌ی ۱ (Coprocessor 1)** اجرا می‌شوند که ثبات‌های خودش را دارد:

- **سی‌ودو ثبات:** از `$f0` تا `$f31`، هر کدام ۳۲ بیتی.
- **دقت ساده (Single precision):** عدد ۳۲ بیتی که در C نوع `float` است. در یک ثبات جا می‌شود.
- **دقت مضاعف (Double precision):** عدد ۶۴ بیتی که در C نوع `double` است. در یک **جفت ثبات زوج و فرد** جا می‌شود، مثلاً `$f0` و `$f1`. در دستورات فقط ثبات زوج را می‌نویسی.

### دستورات اصلی

| دسته | دقت ساده | دقت مضاعف | معنی |
|---|---|---|---|
| بارگذاری | `l.s $f0, 0($t0)` | `l.d $f0, 0($t0)` | از حافظه به ثبات ممیز شناور |
| ذخیره | `s.s $f0, 0($t0)` | `s.d $f0, 0($t0)` | از ثبات به حافظه |
| جمع و تفریق | `add.s`، `sub.s` | `add.d`، `sub.d` | سه‌عملوندی |
| ضرب و تقسیم | `mul.s`، `div.s` | `mul.d`، `div.d` | سه‌عملوندی |
| کپی | `mov.s $f2, $f0` | `mov.d $f2, $f0` | کپی ثبات |
| مقایسه | `c.lt.s $f0, $f2` | `c.lt.d $f0, $f2` | پرچم شرط را ۱ یا ۰ می‌کند |
| پرش | `bc1t L` | `bc1f L` | پرش اگر پرچم ۱ یا ۰ باشد |

چند نکته‌ی مهم:

- **نام واقعی دستورات حافظه:** دستورات `l.s` و `s.s` در واقع `lwc1` و `swc1` هستند. دستورات `l.d` و `s.d` در MIPS32 نسخه‌ی ۲ و بالاتر برابر `ldc1` و `sdc1` هستند و در شبیه‌سازها گاهی به دو دستور `lwc1` تبدیل می‌شوند.
- **ردیف بودن:** عدد دقت مضاعف ۸ بایت است. پس آدرس آن باید مضرب ۸ باشد. در بخش داده قبل از `.double` دستورالعمل `.align 3` را بگذار.
- **مقایسه:** سه نوع مقایسه داریم: `c.eq` (برابر)، `c.lt` (کوچک‌تر) و `c.le` (کوچک‌تر یا مساوی). بزرگ‌تر بودن را با جابه‌جا کردن عملوندها می‌سازیم. مقایسه نتیجه را در یک **پرچم شرط (Condition flag)** می‌نویسد و دستورات `bc1t` و `bc1f` آن را می‌خوانند. این یکی از معدود جاهایی است که MIPS پرچم دارد.
- **انتقال بین دو دسته ثبات:** دستور `mtc1 $t0, $f0` بیت‌های ثبات صحیح را بدون تبدیل به ثبات ممیز شناور می‌برد و `mfc1` برعکس. برای تبدیل مقدار، دستوراتی مثل `cvt.s.w` (صحیح به اعشاری) و `cvt.w.s` (اعشاری به صحیح) داریم.

### قرارداد فراخوانی ممیز شناور

| ثبات | کاربرد |
|---|---|
| ثبات‌های `$f0` و `$f2` | مقدار بازگشتی تابع |
| ثبات‌های `$f12` و `$f14` | دو آرگومان اول ممیز شناور |
| ثبات‌های `$f4` تا `$f10` و `$f16`، `$f18` | موقت، حفظ‌نشده |
| ثبات‌های `$f20` تا `$f30` | ذخیره‌شده، حفظ‌شده |

### مثال: جمع عناصر آرایه‌ی double

```asm
        .data
        .align 3
arr:    .double 1.5, 2.25, -0.75, 4.0
        .text
        .globl main
main:   la   $t0, arr          # p = &arr[0]
        li   $t1, 4            # n = 4
        mtc1 $zero, $f12       # f12 low  = 0
        mtc1 $zero, $f13       # f12 high = 0  -> sum = 0.0
Loop:   l.d  $f2, 0($t0)       # f2 = *p
        add.d $f12, $f12, $f2  # sum += *p
        addi $t0, $t0, 8       # p++
        addi $t1, $t1, -1      # n--
        bne  $t1, $zero, Loop
        li   $v0, 3            # print_double
        syscall                # prints 7.0
        li   $v0, 10
        syscall
```

برای صفر کردن یک ثبات دقت مضاعف، هر دو نیمه‌اش را با `mtc1 $zero` صفر کردیم، چون الگوی بیتی صفر در IEEE 754 همان صفر است. فایل `float-calc1.s` درس مثال کامل‌تری از دستورات ممیز شناور دقت مضاعف است، از جمله `abs.d`، `neg.d`، `sqrt.d` و `round.w.d`.

## ۷. تمرین‌ها

<details>
<summary>تمرین ۱: آزمایش endianness</summary>

**صورت:** برنامه‌ای بنویس که کلمه‌ی 0x11223344 را در حافظه بنویسد و بعد اولین بایت آن را با `lbu` بخواند و چاپ کند. در MARS چه عددی چاپ می‌شود؟

**جواب:**

```asm
        .data
w:      .word 0x11223344
        .text
main:   la   $t0, w
        lbu  $a0, 0($t0)       # first byte
        li   $v0, 34           # MARS: print int in hex
        syscall
        li   $v0, 10
        syscall
```

چون MARS کوچک‌پایان است، بایت آدرس پایین 0x44 است و 0x00000044 چاپ می‌شود. در ماشین بزرگ‌پایان 0x11 چاپ می‌شد. سرویس ۳۴ فقط در MARS هست. در QtSpim از سرویس ۱ استفاده کن که ۶۸ را چاپ می‌کند.
</details>

<details>
<summary>تمرین ۲: میانگین دو عدد اعشاری</summary>

**صورت:** برنامه‌ای بنویس که دو عدد `float` بخواند و میانگینشان را چاپ کند.

**جواب:**

```asm
        .data
two:    .float 2.0
        .text
        .globl main
main:   li   $v0, 6            # read_float -> f0
        syscall
        mov.s $f4, $f0
        li   $v0, 6
        syscall
        add.s $f4, $f4, $f0    # a + b
        l.s  $f6, two
        div.s $f12, $f4, $f6   # (a + b) / 2
        li   $v0, 2            # print_float
        syscall
        li   $v0, 10
        syscall
```

معماری MIPS دستوری برای ثابت ممیز شناور ندارد. پس ثابت ۲ را در بخش داده گذاشتیم و با `l.s` خواندیم.
</details>
