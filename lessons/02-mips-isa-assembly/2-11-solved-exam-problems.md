## ۱. روش حل سؤال‌های برنامه‌نویسی

همه‌ی کدهای این جلسه در یک شبیه‌ساز MIPS با داده‌های تصادفی آزمایش شده‌اند. برای نوشتن جواب امتحانی این روش را پیشنهاد می‌کنم:

1. **اول به C فکر کن.** الگوریتم را چند خط به زبان C بنویس. این کار جلوی خطاهای منطقی را می‌گیرد.
2. **ثبات‌ها را تعیین کن.** یک جدول کوچک بنویس که هر متغیر در کدام ثبات است. صورت سؤال معمولاً بعضی را مشخص کرده است.
3. **اشاره‌گر را ترجیح بده.** به جای اندیس و ضرب در ۴، یک اشاره‌گر بگیر و هر بار ۴ یا ۸ اضافه کن. کد کوتاه‌تر و خطا کمتر می‌شود.
4. **حالت‌های مرزی را بررسی کن.** آرایه‌ی خالی، یک‌عنصری و عناصر تکراری.
5. **توضیح بنویس.** کنار هر دستور یک توضیح کوتاه بگذار. مصحح با آن منطق تو را سریع‌تر می‌فهمد.

## ۲. بیشینه و کمینه در یک حلقه (امتحان ۰۰-۰۱)

**صورت:** آرایه‌ای از عناصر صحیح ۳۲ بیتی داده شده است. طول آرایه در `$s0` و آدرس شروع در `$s1` است. برنامه‌ای بنویس که در یک حلقه بیشینه و کمینه را پیدا کند و به ترتیب در `$t8` و `$t9` بگذارد.

### الگوریتم

```c
max = min = A[0];
for (p = &A[1]; p < &A[n]; p++) {
    if (*p > max) max = *p;
    if (*p < min) min = *p;
}
```

| متغیر | ثبات |
|---|---|
| مقدار `max` | ثبات `$t8` |
| مقدار `min` | ثبات `$t9` |
| اشاره‌گر `p` | ثبات `$t0` |
| آدرس پایان | ثبات `$t1` |
| عنصر جاری `x` | ثبات `$t3` |

### کد

```asm
maxmin: lw    $t8, 0($s1)        # max = A[0]
        move  $t9, $t8           # min = A[0]
        addi  $t0, $s1, 4        # p = &A[1]
        sll   $t1, $s0, 2        # t1 = n * 4
        add   $t1, $s1, $t1      # end = &A[n]
loop:   slt   $t2, $t0, $t1      # p < end ?
        beq   $t2, $zero, done
        lw    $t3, 0($t0)        # x = *p
        slt   $t2, $t8, $t3      # max < x ?
        beq   $t2, $zero, chkmin
        move  $t8, $t3           # max = x
chkmin: slt   $t2, $t3, $t9      # x < min ?
        beq   $t2, $zero, next
        move  $t9, $t3           # min = x
next:   addi  $t0, $t0, 4        # p++
        j     loop
done:
```

### نکته‌ها

- **مقدار اولیه:** بیشینه و کمینه را با اولین عنصر شروع کردیم. این از شروع با یک عدد خیلی کوچک یا خیلی بزرگ امن‌تر است.
- **فرض n بزرگ‌تر از صفر:** اگر آرایه خالی باشد، `A[0]` معنی ندارد. می‌توانی در ابتدا `beq $s0, $zero, done` بگذاری.
- **مقایسه‌ی علامت‌دار:** چون عناصر «صحیح» هستند و منفی هم می‌توانند باشند، از `slt` استفاده کردیم و نه `sltu`.
- **یک بهبود:** اگر عنصری از بیشینه بزرگ‌تر باشد، دیگر لازم نیست با کمینه مقایسه شود. می‌توان بعد از `move $t8, $t3` مستقیماً به `next` پرید. این کار هم درست است و هم کمی سریع‌تر.

## ۳. کمینه‌ی اول و دوم (امتحان ۰۱-۰۲)

**صورت:** همان آرایه. در یک حلقه کمینه‌ی اول و دوم را پیدا کن و به ترتیب در `$t8` و `$t9` بگذار.

### الگوریتم

کلید حل این است: وقتی عنصری از کمینه‌ی اول کوچک‌تر است، کمینه‌ی اول قبلی تبدیل به کمینه‌ی دوم می‌شود.

```c
min1 = min2 = INT_MAX;
for (p = &A[0]; p != &A[n]; p++) {
    x = *p;
    if (x < min1)      { min2 = min1; min1 = x; }
    else if (x < min2) { min2 = x; }
}
```

### کد

```asm
min2:   lui   $t8, 0x7fff
        ori   $t8, $t8, 0xffff   # min1 = INT_MAX
        move  $t9, $t8           # min2 = INT_MAX
        move  $t0, $s1           # p = &A[0]
        sll   $t1, $s0, 2
        add   $t1, $s1, $t1      # end = &A[n]
loop:   beq   $t0, $t1, done
        lw    $t3, 0($t0)        # x = *p
        slt   $t2, $t3, $t8      # x < min1 ?
        beq   $t2, $zero, else
        move  $t9, $t8           # min2 = min1
        move  $t8, $t3           # min1 = x
        j     next
else:   slt   $t2, $t3, $t9      # x < min2 ?
        beq   $t2, $zero, next
        move  $t9, $t3           # min2 = x
next:   addi  $t0, $t0, 4
        j     loop
done:
```

### نکته‌ها

- **ساختن INT_MAX:** عدد 0x7FFFFFFF در ۱۶ بیت جا نمی‌شود. پس با `lui` و `ori` ساخته شد (جلسه‌ی ۲-۷). می‌توانی شبه‌دستور `li $t8, 0x7fffffff` را هم بنویسی.
- **مقدار اولیه‌ی دیگر:** راه دیگر این است که دو عنصر اول را مقایسه کنی و کوچک‌تر را min1 و بزرگ‌تر را min2 بگذاری. این روش به INT_MAX نیاز ندارد ولی آرایه باید دست‌کم دو عنصر داشته باشد.
- **عناصر تکراری:** اگر کمینه دو بار تکرار شده باشد، مثلاً آرایه‌ی `5, -3, 17, 2, -8, 9, -8, 40`، این کد هر دو را −8 می‌دهد. اگر منظور سؤال «دومین مقدار متمایز» باشد (جواب −3)، یک خط اضافه کن:

```asm
else:   beq   $t3, $t8, next     # skip duplicates of min1
        slt   $t2, $t3, $t9      # x < min2 ?
```

در برگه‌ی امتحان فرضت را بنویس: «فرض کرده‌ام عناصر تکراری حساب می‌شوند» یا برعکس.

## ۴. برعکس کردن آرایه‌ی ممیز شناور (امتحان ۹۵-۹۶ و ۹۹-۰۰)

**صورت:** آرایه‌ای از عناصر ممیز شناور ۶۴ بیتی داده شده است. طول در `$s0` و آدرس شروع در `$s1` است. برنامه‌ای بنویس که ترتیب عناصر را برعکس کند.

### الگوریتم

دو اشاره‌گر، یکی از ابتدا و یکی از انتها، به سمت هم حرکت می‌کنند و عناصر را جابه‌جا می‌کنند:

```c
left = &A[0]; right = &A[n-1];
while (left < right) {
    a = *left; b = *right;
    *left = b; *right = a;
    left++; right--;
}
```

### کد

هر عنصر ۸ بایت است، پس اشاره‌گرها ۸ تا ۸ تا حرکت می‌کنند:

```asm
reverse: move  $t0, $s1          # left  = &A[0]
         sll   $t1, $s0, 3       # t1 = n * 8
         add   $t1, $s1, $t1
         addi  $t1, $t1, -8      # right = &A[n-1]
loop:    slt   $t2, $t0, $t1     # left < right ?
         beq   $t2, $zero, done
         l.d   $f0, 0($t0)       # a = *left
         l.d   $f2, 0($t1)       # b = *right
         s.d   $f2, 0($t0)       # *left  = b
         s.d   $f0, 0($t1)       # *right = a
         addi  $t0, $t0, 8       # left++
         addi  $t1, $t1, -8      # right--
         j     loop
done:
```

### نکته‌ها

- **ضرب در ۸:** برای عنصر ۶۴ بیتی شیفت به اندازه‌ی ۳ بیت است، نه ۲.
- **ثبات‌های زوج:** هر عدد دقت مضاعف یک جفت ثبات می‌گیرد. پس از `$f0` و `$f2` استفاده کردیم و نه `$f0` و `$f1`.
- **نیازی به محاسبه نیست:** چون فقط جابه‌جا می‌کنیم و حسابی انجام نمی‌دهیم، می‌توانستیم هر عنصر را با دو `lw` و دو `sw` ثبات‌های صحیح هم جابه‌جا کنیم. ولی صورت سؤال آرایه‌ی ممیز شناور گفته و `l.d` و `s.d` طبیعی‌ترند.
- **تعداد زوج و فرد:** اگر n فرد باشد، عنصر وسط سر جایش می‌ماند و شرط `left < right` درست کار می‌کند. اگر n صفر باشد، `right` از `left` کوچک‌تر است و حلقه اجرا نمی‌شود.
- **ادامه‌ی سؤال:** قسمت‌های بعدی امتحان ۹۵-۹۶ باز کردن حلقه با تأخیرهای مشخص و نوشتن نسخه‌ی برداری را می‌خواهند. این‌ها را در بخش ۷ و بخش ۹ حل می‌کنیم.

## ۵. مرتب‌سازی سریع روی آرایه‌ی ممیز شناور (تمرین درس)

**صورت:** برنامه‌ای به زبان اسمبلی MIPS بنویس که الگوریتم QuickSort را بر اساس شبه‌کد داده‌شده، روی یک آرایه‌ی ممیز شناور پیاده کند. برنامه‌ی اصلی آرایه را از ورودی بگیرد، مرتب کند و چاپ کند.

### ایرادهای شبه‌کد صورت تمرین

قبل از نوشتن اسمبلی، باید مطمئن شویم شبه‌کد درست است. شبه‌کد صورت تمرین سه ایراد دارد:

- **نبود حالت پایه:** رویه‌ی `QuickSort(A, i, j)` هیچ شرطی برای توقف ندارد. باید فقط وقتی `i < j` است کار کند.
- **محور سر جایش قرار نمی‌گیرد:** در `Partition` عنصر محور `x = A[p]` هیچ‌وقت به جای نهایی‌اش منتقل نمی‌شود. در پایان باید `A[p]` با `A[j]` جابه‌جا شود.
- **بازگشت بی‌پایان:** فراخوانی `QuickSort(A, i, k)` بازه را کوچک نمی‌کند اگر `k = j` باشد. مثلاً برای آرایه‌ی `1, 2`، رویه‌ی Partition مقدار `j` یعنی ۲ را برمی‌گرداند و دوباره `QuickSort(A, 1, 2)` صدا زده می‌شود. باید `QuickSort(A, i, k-1)` باشد، که بعد از قرار دادن محور در خانه‌ی k درست است.

یک ایراد کوچک‌تر هم دارد: با شرط `while (i < j)`، اگر بازه فقط دو عنصر داشته باشد، حلقه اصلاً اجرا نمی‌شود. با `while (i <= j)` درست کار می‌کند.

### شبه‌کد اصلاح‌شده

```c
int Partition(float A[], int p, int q) {
    float x = A[p];
    int i = p + 1, j = q;
    while (i <= j) {
        while (i <= q && A[i] <= x) i++;
        while (A[j] > x) j--;          /* stops at p, since A[p] == x */
        if (i < j) { swap(A[i], A[j]); i++; j--; }
    }
    swap(A[p], A[j]);                  /* put pivot in its final place */
    return j;
}

void QuickSort(float A[], int lo, int hi) {
    if (lo < hi) {
        int k = Partition(A, lo, hi);
        QuickSort(A, lo, k - 1);
        QuickSort(A, k + 1, hi);
    }
}
```

اندیس‌ها را از صفر گرفتیم، مثل C. یعنی برنامه‌ی اصلی `QuickSort(A, 0, n-1)` را صدا می‌زند.

### تخصیص ثبات

| رویه | متغیر | ثبات |
|---|---|---|
| رویه‌ی `Partition` (برگ) | آدرس `A`، اندیس `p`، اندیس `q` | ثبات‌های `$a0`، `$a1`، `$a2` |
| رویه‌ی `Partition` | محور `x` | ثبات `$f0` |
| رویه‌ی `Partition` | اندیس‌های `i` و `j` | ثبات‌های `$t1` و `$t2` |
| رویه‌ی `Partition` | خانه‌های `A[i]` و `A[j]` | ثبات‌های `$f2` و `$f4` |
| رویه‌ی `QuickSort` (غیربرگ) | آدرس `A`، `lo`، `hi` | ثبات‌های `$a0`، `$a1`، `$a2` و ذخیره روی پشته |
| رویه‌ی `QuickSort` | خروجی `k` | ثبات `$v0` و ذخیره روی پشته |
| رویه‌ی `main` | تعداد `n` | ثبات `$s0` |

رویه‌ی `Partition` برگ است و فقط از ثبات‌های `$t` و `$f` موقت استفاده می‌کند. پس به پشته نیاز ندارد. رویه‌ی `QuickSort` دو بار خودش را صدا می‌زند، پس باید `$ra`، آرگومان‌ها و `k` را روی پشته نگه دارد.

### کد کامل

```asm
# QuickSort on an array of single-precision floats (QtSpim / MARS)
        .data
A:      .space  400              # room for 100 floats
msg_n:  .asciiz "n = "
msg_x:  .asciiz "x = "
nl:     .asciiz "\n"

        .text
        .globl  main
main:   addi  $sp, $sp, -8
        sw    $ra, 4($sp)
        sw    $s0, 0($sp)
        la    $a0, msg_n         # print "n = "
        li    $v0, 4
        syscall
        li    $v0, 5             # read int n
        syscall
        move  $s0, $v0           # s0 = n
        la    $t0, A             # t0 = &A[0]
        li    $t1, 0             # k = 0
rd:     beq   $t1, $s0, rd_end
        la    $a0, msg_x
        li    $v0, 4
        syscall
        li    $v0, 6             # read float -> $f0
        syscall
        s.s   $f0, 0($t0)
        addi  $t0, $t0, 4
        addi  $t1, $t1, 1
        j     rd
rd_end: la    $a0, A             # QuickSort(A, 0, n-1)
        li    $a1, 0
        addi  $a2, $s0, -1
        jal   quicksort
        la    $t0, A             # print A
        li    $t1, 0
pr:     beq   $t1, $s0, pr_end
        l.s   $f12, 0($t0)
        li    $v0, 2
        syscall
        la    $a0, nl
        li    $v0, 4
        syscall
        addi  $t0, $t0, 4
        addi  $t1, $t1, 1
        j     pr
pr_end: lw    $s0, 0($sp)
        lw    $ra, 4($sp)
        addi  $sp, $sp, 8
        li    $v0, 10            # exit
        syscall

# quicksort(a0 = &A[0], a1 = lo, a2 = hi)
quicksort:
        slt   $t0, $a1, $a2      # lo < hi ?
        beq   $t0, $zero, qs_ret
        addi  $sp, $sp, -20
        sw    $ra, 16($sp)
        sw    $a0, 12($sp)
        sw    $a1, 8($sp)
        sw    $a2, 4($sp)
        jal   partition          # v0 = k
        sw    $v0, 0($sp)
        lw    $a0, 12($sp)       # QuickSort(A, lo, k-1)
        lw    $a1, 8($sp)
        addi  $a2, $v0, -1
        jal   quicksort
        lw    $a0, 12($sp)       # QuickSort(A, k+1, hi)
        lw    $t0, 0($sp)
        addi  $a1, $t0, 1
        lw    $a2, 4($sp)
        jal   quicksort
        lw    $ra, 16($sp)
        addi  $sp, $sp, 20
qs_ret: jr    $ra

# partition(a0 = &A[0], a1 = p, a2 = q) -> v0 = final pivot index (leaf)
partition:
        sll   $t0, $a1, 2
        add   $t0, $a0, $t0      # t0 = &A[p]
        l.s   $f0, 0($t0)        # x = A[p]
        addi  $t1, $a1, 1        # i = p + 1
        move  $t2, $a2           # j = q
p_loop: slt   $t3, $t2, $t1      # while (i <= j)
        bne   $t3, $zero, p_end
i_loop: slt   $t3, $a2, $t1      # i > q ?  stop
        bne   $t3, $zero, j_loop
        sll   $t4, $t1, 2
        add   $t4, $a0, $t4
        l.s   $f2, 0($t4)        # A[i]
        c.le.s $f2, $f0          # A[i] <= x ?
        bc1f  j_loop
        addi  $t1, $t1, 1        # i++
        j     i_loop
j_loop: sll   $t5, $t2, 2
        add   $t5, $a0, $t5
        l.s   $f4, 0($t5)        # A[j]
        c.le.s $f4, $f0          # A[j] <= x ?  stop
        bc1t  test
        addi  $t2, $t2, -1       # j--
        j     j_loop
test:   slt   $t3, $t1, $t2      # if (i < j) exchange
        beq   $t3, $zero, p_loop
        sll   $t4, $t1, 2
        add   $t4, $a0, $t4
        l.s   $f2, 0($t4)
        s.s   $f4, 0($t4)        # A[i] = old A[j]
        s.s   $f2, 0($t5)        # A[j] = old A[i]
        addi  $t1, $t1, 1
        addi  $t2, $t2, -1
        j     p_loop
p_end:  sll   $t5, $t2, 2        # exchange A[p] and A[j]
        add   $t5, $a0, $t5
        l.s   $f4, 0($t5)
        s.s   $f4, 0($t0)
        s.s   $f0, 0($t5)
        move  $v0, $t2
        jr    $ra
```

### نکته‌های کد

- **شرط «بزرگ‌تر از» در ممیز شناور:** MIPS دستور `c.gt.s` ندارد. شرط `A[j] > x` را به شکل «نه `A[j] <= x`» نوشتیم: `c.le.s` و بعد `bc1t` برای توقف.
- **آدرس دوباره حساب می‌شود:** در بخش `test` آدرس `A[i]` را دوباره حساب کردیم. دلیلش این است که اگر حلقه‌ی `i_loop` به دلیل `i > q` تمام شده باشد، `$t4` مقدار قدیمی دارد.
- **حفظ `$a0`:** رویه‌ی `partition` مقدار `$a0` را تغییر نمی‌دهد. ولی طبق قرارداد، `QuickSort` نباید به این تکیه کند. پس `$a0` را هم روی پشته ذخیره کردیم.
- **عمق پشته:** در بدترین حالت (آرایه‌ی از قبل مرتب) عمق بازگشت برابر n است و هر سطح ۲۰ بایت پشته می‌گیرد. برای ۱۰۰ عنصر این مقدار مشکلی ایجاد نمی‌کند.
- **دقت مضاعف:** اگر بخواهی آرایه از نوع `double` باشد، `.s` را به `.d` تبدیل کن، ضرب در ۴ را به ضرب در ۸ (شیفت ۳) تغییر بده، سرویس خواندن را ۷ و چاپ را ۳ بگذار و از ثبات‌های زوج استفاده کن.

## ۶. پاسخ کوتاه: اصول طراحی MIPS-I

**صورت (امتحان ۹۵-۹۶ و ۹۹-۰۰):** اصول رعایت‌شده در طراحی MIPS-I را در حداکثر سه خط بنویس.

**جواب نمونه:**

چهار اصل: سادگی با نظم (طول ثابت ۳۲ بیتی، سه قالب، سه عملوند در جای ثابت)، کوچک‌تر سریع‌تر است (فقط ۳۲ ثبات)، حالت رایج را سریع کن (ثابت داخل دستور، ثبات صفر، پرش نسبی به PC) و طراحی خوب مصالحه‌ی خوب می‌خواهد (چند قالب با حفظ طول ثابت). همچنین معماری بارگذاری و ذخیره و ردیف بودن حافظه برای ساده شدن خط لوله.

اگر وقت بیشتری هست، می‌توان این‌ها را هم گفت: نبود کد شرط و پرچم، پنج روش آدرس‌دهی ساده، شکاف تأخیر پرش و نبود قفل سخت‌افزاری در خط لوله (که اسم MIPS از آن آمده).

## ۷. برنامه‌ی آزمایش در شبیه‌ساز

سه رویه‌ی بخش ۲ تا ۴ برنامه‌ی کامل نیستند. برای آزمایش آن‌ها در QtSpim یا MARS این قالب را به کار ببر. داده‌ها را دلخواه تغییر بده و بعد از اجرا، مقدار `$t8` و `$t9` را در پنجره‌ی ثبات‌ها ببین:

```asm
        .data
arr:    .word 5, -3, 17, 2, -8, 9, -8, 40
        .text
        .globl main
main:   la    $s1, arr           # base address
        li    $s0, 8             # number of elements
        # ---- paste the body of maxmin or min2 here ----
        li    $v0, 10            # exit
        syscall
```

جواب مورد انتظار برای این داده‌ها:

| برنامه | مقدار `$t8` | مقدار `$t9` |
|---|---|---|
| برنامه‌ی بیشینه و کمینه | 40 | −8 |
| برنامه‌ی کمینه‌ی اول و دوم | −8 | −8 |
| کمینه‌ی دوم با حذف تکرار | −8 | −3 |

برای برنامه‌ی برعکس کردن، آرایه را با `.align 3` و `.double` تعریف کن، `$s0` را تعداد عناصر بگذار و بعد از اجرا محتوای حافظه را در پنجره‌ی Data ببین.
