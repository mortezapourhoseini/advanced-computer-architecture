# بخش ۹: موازی‌سازی سطح داده: معماری برداری، SIMD و GPU

این بخش در چهارده جلسه‌ی حدوداً نیم‌ساعته تنظیم شده است. جلسه‌ها را به ترتیب بخوان، چون هر جلسه از مفاهیم جلسه‌های قبل استفاده می‌کند. در این بخش از معماری برداری VMIPS شروع می‌کنیم و زمان اجرا را با کاروان، چایم، زنجیره‌سازی، خط‌ها، قطعه‌بندی و مدل دقیق پیوست G می‌سازیم. بعد ثبات نقاب، بانک‌های حافظه، گام و جمع‌آوری و پخش را می‌بینیم و دو سؤال امتحانی را با VMIPS و RV64V حل می‌کنیم. سپس افزونه‌های SIMD چندرسانه‌ای و مدل Roofline را با آزمایش عملی بررسی می‌کنیم، و در پایان GPU را از مدل برنامه‌نویسی CUDA تا سخت‌افزار، PTX، واگرایی، حافظه و Fermi می‌شناسیم و سه معماری را با هم و با سیستم‌های واقعی مقایسه می‌کنیم.
