# معماری کامپیوتر پیشرفته (Advanced Computer Architecture)

جزوه‌ی خودآموز و کامل درس **معماری کامپیوتر پیشرفته** — کارشناسی ارشد معماری کامپیوتر، دانشگاه تربیت مدرس (نیم‌سال اول ۱۴۰۵-۱۴۰۶).

هر بخش یک فایل Markdown است که این‌ها را دارد: توضیح مفاهیم به زبان ساده، مثال‌های حل‌شده‌ی اسلایدها، **حل سؤال‌های امتحان‌های پایان‌ترم قبلی**، تمرین خودآزمایی با جواب، **معادل مفاهیم در پردازنده‌ی ARM Cortex-A9** و واژه‌نامه‌ی انگلیسی-فارسی.

- **پایه‌ی درس:** معماری **MIPS**؛ هر جا لازم باشد معادل **RISC-V** هم گفته می‌شود.
- **زبان:** فارسی، با اصطلاحات تخصصی انگلیسی.
